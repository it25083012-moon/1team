# 🏠 Pixel Ibasho Project

> **「子どもがつくる、子どもとつくる」**
> 不登校やコミュニケーションに不安を抱える小学生が、ドット絵の世界で段階的に繋がりを広げ、最終的に対面での交流（カレーパーティー）を目指す1ヶ月間のステップアップ型・居場所づくりアプリ。

> 📌 ここに完成画面のスクリーンショットやデモのリンクを入れてください

---

## 📖 プロジェクト概要

本プロジェクトは、**東京シューレ江戸川小学校**の「子どもがつくる」精神を軸に開発されているコミュニティ＆学習支援アプリです。
オンラインでのコミュニケーションに心理的ハードルを感じる子どもたちが、段階的（1人 ➔ 2人 ➔ 小グループ ➔ 全員）に共同作業を重ねることで、無理なく社会性を育み、「自分はひとりじゃない」と実感できる場を提供します。

---

## 🗓️ 1ヶ月（4週間）ステップアップ・ロードマップ

1週間ごとに1つの課題（ミッション）をクリアしながら、緩やかに交流範囲を広げていきます。

| 周次 | 対象人数 | フェーズ名 | 課題内容（ミッション） | 達成ゴール |
| :--- | :--- | :--- | :--- | :--- |
| **Week 1** | **1人** | 自分を表現する | プロフィール作成、マイアイコンや「心ステッカー」のドット絵作成 | 自分だけの「居場所」をアプリ内に作る |
| **Week 2** | **2人** | ペアでつくる | 2人1組でキャンバスの左右を分担描画し、AIで1つの動くキャラを生成 | 「はんぶんこAIキャラクター」の完成 |
| **Week 3** | **4〜10人** | チームで企画する | 小グループで協力し、対面イベントに向けた「特製カレーレシピ」を考案 | カレーの具材ミッション達成＆ストーリー完成 |
| **Week 4** | **20人** | みんなで会う | 20人全員でオンライン事前準備を行い、実際に顔を合わせる対面イベント | **リアル対面カレーパーティー**の開催 |

---

## ✨ 主な機能と特徴

* **温かみのある2Dドット絵（ピクセルアート）UI**
  * レトロゲームのような世界観で、勉強や交流への圧迫感を軽減。
* **はんぶんこAIキャンバス**
  * ペアで絵を分担して描き、AIが1つの動き出すキャラクターへ合成・アニメーション化する協力ツール。
* **カレー具材獲得ミッション**
  * 各課題を達成するごとに、鍋にニンジン・ジャガイモ・タマネギ・ルーなどの具材が集まる達成感の可視化システム。
* **心理的安全性の確保**
  * 匿名性の適切なコントロール（ニックネームのみ）、先生・ファシリテーターによる見守り体制、評価ストレスを与えない設計（「いいね」や点数なし・参加は「おやすみ」もOK）。

---

## 🛠️ 技術スタック

* **Frontend:** HTML5, CSS3, JavaScript (ES6+ / ES Modules)
* **Graphics / UI:** HTML5 Canvas API (Pixel Art Renderer)
* **AI Engine:** 画像生成・合成API（キャラクター・アニメーション生成用）
  * 未設定の間は、ブラウザ内の簡易処理（つなぎ目補正＋ふちどり＋2コマアニメ）で代用します。
* **Data Storage:** Firebase (Firestore / Authentication)
  * 未設定の間は、ブラウザの `localStorage` で動く「おためしモード」になります。

## 🚀 ローカル環境での実行方法

```bash
# リポジトリのクローン
git clone https://github.com/your-username/pixel-ibasho-project.git

# ディレクトリへ移動
cd pixel-ibasho-project

# ローカルサーバーの起動（例: Pythonを使用する場合）
python -m http.server 8000
```

ブラウザで <http://localhost:8000> を開いてください。
ES Modules を使っているため、`index.html` をダブルクリックで開くだけでは動きません。必ずローカルサーバー経由で開いてください。

### おためしモード（Firebase なし）

何も設定しなくても動きます。データはそのブラウザの `localStorage` にだけ保存されます。
ペア（Week 2）やチーム（Week 3）の動作確認は、同じブラウザの別タブで同じ「あいことば」を入れると試せます。

---

## 🔥 Firebase の設定（本番用）

1. [Firebase コンソール](https://console.firebase.google.com/) でプロジェクトを作成し、**ウェブアプリ**を追加します。
2. **Authentication** で「匿名」ログインを有効にします。
3. **Firestore Database** を作成します。
4. 表示された設定値を `js/firebase.js` 上部の `FIREBASE_CONFIG` に貼り付けます。
5. Firestore のセキュリティルールを設定します（例）。

```text
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    // 自分のプロフィールは自分だけが読み書きできる
    match /users/{uid} {
      allow read, write: if request.auth != null && request.auth.uid == uid;
    }
    // ペア・チームのデータは、ログイン済みで「あいことば」を知っている人だけ
    match /pairs/{code} {
      allow read, write: if request.auth != null;
    }
    match /teams/{code} {
      allow read, write: if request.auth != null;
    }
  }
}
```

> ⚠️ 上のルールは試作用です。実際に子どもが使う前に、先生・ファシリテーターによる見守り用の権限や、
> 「あいことば」の推測されにくさ（長くする・先生が配る）を必ず見直してください。

## 🤖 AI（はんぶんこキャラ）の接続

`js/canvas.js` の `AI_CONFIG.endpoint` に、自分のサーバー（Cloud Functions など）のURLを設定すると、
そちらに `{ pixels, cols, rows }` を POST し、`{ pixels }` が返ってくる想定で動きます。

* **APIキーをブラウザのコードに直接書かないでください。** 必ずサーバー側で保持します。
* 子どもが描いた絵を外部へ送るため、保護者・学校への説明と同意、利用規約の確認が必要です。
